PANDAS ANALYZER & DATA VISUALIZATION

How to run:
1. Install Python.
2. Open this folder in VS Code.
3. Open Terminal.
4. Run: pip install -r requirements.txt
5. Run: python main.py
6. Select option 1 to load the sample CSV file.

Project files:
main.py                  Main Python program
data/sales_data.csv      Sample sales data
outputs/                 Saved chart and CSV files

This is a basic student-level version. It uses simple class methods,
if-else conditions, loops, Pandas, Matplotlib and Seaborn.

Note:
The program loads the included CSV file from data/sales_data.csv.
Run main.py from the main project folder.
